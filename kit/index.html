自走キットとは

AIコーディングエージェントに、プロジェクトの「運用」を任せるための設定一式です。人間が担当するのは、アカウント開設・貼り付け・設定変更・入金の受け取りなどの手を動かす作業と、法的な決断だけ。企画・文面・制作・分析・毎日の指示出しはAIが行います。

毎日のループ（v1.5 の CLAUDE.md の要約）

  1. 起動時のフックの出力で、計画の要点・何日目か・残り日数・数字画像を作る日か・台帳の直近を確かめる
  2. 人間の報告があれば台帳（LEDGER.md）に記録する。数字は盛らない。無い数字は「-」
  3. 日付が今日以前でまだ判定していない判断ルールを照らし、結果を台帳に1行ずつ残す。完成した数は「完成の数え方」どおりに数える。発火したら計画を変える
  4. 今日の成果物（投稿文・記事・商品・分析）を作る
  5. 人間の作業を ops/dayNN.md に書く。書く前に、台帳の決定事項と前の指示書の予告を写して照らす。コピペで済む粒度、順番つき、所要時間つき
  6. 投稿文は文字数を、商品文は禁止語を、スクリプトで確認してから渡す。台帳と指示書も、書式をスクリプトで確認してから渡し、人間への報告も長さ・見出し・前日比・パスをスクリプトで確認してから返す

向く人・向かない人

  • 向く：Claude Code を入れたが毎回の指示出しが手間で、日報・台帳・指示書まで任せたい人。個人開発や副業の発信と販売まで、「AIが回し、人間は手を動かす作業と法的な決断だけ」の分業で続けたい人
  • 試した計画：実物のセッションは架空の技術同人誌（PDF を BOOTH で頒布）と、v1.5 を Sonnet で開始前日と Day 1 の2日だけ回した note の有料記事（14日で3本）の2つ、予行（方法B）は技術同人誌に note の有料記事と Chrome 拡張（作って無料で公開）を足した3つです。Kindle の本など、ほかの計画では回していません
  • 向かない：収益や成果の約束を求める人。本キットは運用の型で、売上を約束するものではありません。作った私自身の挑戦も、このページを更新した 2026-10-28 の朝の時点で売上 ¥0 です（毎日の数字は公開台帳）。また、この一式は、作ったものを X・note などで公開・販売する個人のプロジェクトを想定した型です（台帳の列は投稿数・imp・フォロワー・PV・購入・売上・手取りなど）。有料版だけにあるもののうち、投稿の文字数と禁止語のチェック、数字画像、手引きの法律チェックは公開・販売のためのものです。それ以外の差（台帳と指示書の書式チェック〔報告の書式チェックは下の表〕、v1.5 の文の4ファイル、手引き、TESTLOG.md など）は下の表のとおりで、開発の運用だけが目的なら、まず無料版か本で足りるかを確かめてください
