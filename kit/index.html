自走キットとは

AIコーディングエージェントに、プロジェクトの「運用」を任せるための設定一式です。人間が担当するのは、アカウント開設・貼り付け・設定変更・入金の受け取りなど、手を動かす作業だけ。企画・文面・制作・分析・毎日の指示出しはAIが行います。

毎日のループ（Brain 版 v1.1 の CLAUDE.md の要約）

  1. 起動時のフックの出力で、計画の要点・何日目か・残り日数・台帳の直近を確かめる
  2. 人間の報告があれば台帳（LEDGER.md）に記録する。数字は盛らない。無い数字は「-」
  3. 日付が今日以前でまだ判定していない判断ルールを照らし、結果を台帳に1行ずつ残す。発火したら計画を変える
  4. 今日の成果物（投稿文・記事・商品・分析）を作る
  5. 人間の作業を ops/dayNN.md に書く。コピペで済む粒度、順番つき、所要時間つき
  6. 投稿文は文字数を、商品文は禁止語を、スクリプトで確認してから渡す

向く人・向かない人

  • 向く：Claude Code を入れたが毎回の指示出しが手間で、日報・台帳・指示書まで任せたい人。個人開発や副業の発信と販売まで、「AIが回し、人間は手を動かす作業だけ」の分業で続けたい人
  • 向かない：収益や成果の約束を求める人。本キットは運用の型で、売上を約束するものではありません。作った私自身の挑戦も、このページを書き換えた 2026-10-21 の時点で売上 ¥0 です（毎日の数字は公開台帳）。また、有料版で増える道具の多くは、X・note で公開・販売する人向けです。開発の運用が目的なら、無料版か本が合います

PASS／FAIL は採点の項目ごとの判定です。線の付いた「v1.5」の行に、v1.5 で直したことと、直していないこと（とその理由）を書きました。

  • FAIL　判断ルール：成果物より前に決定事項へ1行残す流れと書式は合っていたが、根拠の「第2章はコードを全部再実行して本の出力と一致」が事実でなかった（再実行は一部だけで、Day 2 の食い違いも残ったまま）。定義どおりに数えると、判定の時点で完成は 1/8章v1.5：CLAUDE.md に「完成の数え方」の節を足した。完成と数えるのは条件を実際に確かめたものだけ、食い違いが見つかったものは前の日に数えていても外す、判断ルールを判定する日はその日に確かめ直す
